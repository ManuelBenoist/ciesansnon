# AGENTS.md — La Cie Sans Non

Stack : Nuxt 4 (SSG) · Tailwind CSS · Nuxt Content v3 · Formspree · motion-v · @nuxtjs/sitemap · GitHub Actions → GitHub Pages

## Commands
```bash
npm run dev        # dev server on localhost:3000
npm run generate   # static export → .output/public/ (single source of truth)
npm run preview    # preview production build locally
```

## Key architectural facts
- Nuxt 4 with `future: { compatibilityVersion: 4 }` — `app/` directory as app root
- SSG mode: `nitro.preset: 'github-pages'` — no server routes
- Custom colors via `scene-*` Tailwind palette (`scene-brick` gold accent, `scene-rouge` badges). Full palette in `tailwind.config.ts`
- Fonts auto-hosted via @fontsource (`Nunito Sans` display, `DM Sans` body, `Cormorant Garamond` serif)
- Animations: CSS transitions + motion-v (plugin at `app/plugins/motion.client.ts`)
- Icons via `@nuxt/icon` — `<Icon name="mdi:instagram" />`
- Form: Formspree AJAX via `useFormspree` composable (set `NUXT_PUBLIC_FORMSPREE_ID` in `.env`)
- SEO: `useSeo()` composable wraps `useSeoMeta` + `useHead` (french lang, OG, Twitter card). Import `safeJsonLd` from `app/utils/safeJsonLd.ts` for JSON-LD script tags
- Sitemap auto-generated by `@nuxtjs/sitemap` module
- Nuxt Content v3 with `highlight: false` in nuxt.config (syntax highlighting disabled — not needed)
- Logo (`logo_csn.webp`) is dark on dark bg → `brightness-[1.6]` in AppHeader/AppFooter/AppNav/la-compagnie. Remove filter if logo is replaced

## Image handling
- All images use `<NuxtImg>` (no CSS `background-image`). Photos in `public/images/`
- `nuxt.config.ts` sets `image: { quality: 85, format: ['webp', 'jpg'] }`
- `scripts/optimize-images.mjs` converts JPEG galerie photos to WebP via `sharp` — run manually when adding raw JPGs:
  ```bash
  node scripts/optimize-images.mjs
  ```

## Content collections (`content.config.ts`)
- **Mandatory** for `queryCollection` `where()`/`order()` on custom fields
- `creations` (type: `page`, source: `creations/*.md`), `membres` (type: `page`, source: `membres/*.md`)
- `ateliers` (type: `data`, source: `ateliers/*.md`), `ateliers_creation` (type: `data`, source: `ateliers-creation/*.md`)
- Use `type: 'data'` for non-page content (no auto `path` field)
- Always `await useAsyncData('key', () => queryCollection(...).all())` inside page `<script setup>`

## Navigation gotchas (CRITICAL)

### 1. Single root node for page transitions
Every page under `<NuxtPage>` must render a single DOM element as its root.
- Nuxt uses `pageTransition: { name: 'page', mode: 'out-in' }` by default
- Vue `<Transition mode="out-in">` requires exactly one element root. Multiple roots, conditional roots (`v-if`/`v-else` at top level), or `<template>` fragments break the transition
- **Symptom**: leaving a dynamic page (`/creations/[slug]`) shows only header/footer; console warns:
  - `Component inside <Transition> renders non-element root node that cannot be animated.`
- **Fix**: wrap the entire page template in one `<div>`, even with `v-if`/`v-else`:
  ```vue
  <template>
    <div>
      <div v-if="!data">Loading...</div>
      <template v-else>...</template>
    </div>
  </template>
  ```

### 2. Never use `definePageMeta({ key: route => route.fullPath })` on dynamic pages
- Breaks client-side navigation with `pageTransition: { mode: 'out-in' }`
- **Fix**: pass a **function** as the `useAsyncData` key instead:
  ```ts
  const { data: creation } = await useAsyncData(
    () => `creation-${route.params.slug}`,
    () => queryCollection('creations').where('slug', '==', route.params.slug).first()
  )
  ```

## Conventions
- YAML frontmatter: `snake_case` (e.g. `role_compagnie`, `role_court`). Vue props: `camelCase` (e.g. `roleCourt`)
- Component naming: directory-prefixed multi-word, e.g. `compagnie/MembreCard.vue`, `spectacle/Card.vue`
- ESLint (`@nuxt/eslint`) and Prettier in devDependencies but **no config files exist** — no lint/format commands
- Verify with `npm run generate`

## Deployment (GitHub Actions → GitHub Pages)
- CI at `.github/workflows/deploy.yml`: `npm ci` → `npm run generate` → upload `.output/public/` → deploy-pages
- `nitro.preset: 'github-pages'` (SPA fallback via 404.html). **No `app.baseURL`** — served at root of custom domain
- `site.url: 'https://ciesansnon.com'`. `public/CNAME` contains the domain. `public/.nojekyll` disables Jekyll
- `NUXT_PUBLIC_FORMSPREE_ID` must be set in GitHub repo secrets for production

## Pre-deployment checklist
Before merging to `main`:
- [ ] `npm run generate` passes without errors
- [ ] `.output/public/sitemap.xml` exists and contains all routes
- [ ] Every page calls `useSeo()` (title, description, canonical, OG tags)
- [ ] JSON-LD is valid on key pages (home, compagnie, spectacle, contact)
- [ ] Images referenced in `content/` files exist in `public/images/`
- [ ] No accidental `noindex` on public pages
- [ ] `robots.txt` is present in `public/`
